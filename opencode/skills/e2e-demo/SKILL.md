# Skill: E2E Demo

## Назначение

Этот навык предназначен для **демонстрации** E2E-тестов, а не для их автоматического прогона.
Он выполняет сценарий **медленно**, с **короткими паузами** между действиями, и **подробно комментирует** каждый шаг в консоли, где запущен OpenCode.

Навык может открывать любые внешние приложения (браузер, терминал, GUI-программы), необходимые для демонстрации.

## Триггер загрузки

Загружайте навык, когда пользователь просит:
- «покажи, как выполняется E2E-тест»
- «продемонстрируй сценарий на экране»
- «запусти E2E с паузами и объяснениями»

## Правила выполнения

1. **Не торопиться.** После каждого значимого действия делайте паузу **1–3 секунды** (или больше, если действие долгое).
2. **Объяснять в консоль.** Перед каждым действием выводите сообщение вида:
   ```
   [E2E DEMO] Шаг 1: Открываю браузер...
   [E2E DEMO] Ожидаю загрузки страницы...
   [E2E DEMO] Результат: страница загружена, заголовок "Example Domain"
   ```
3. **Открывать внешние приложения.** Используйте `bash` для запуска браузеров, терминалов, GUI-приложений или любых других инструментов, необходимых для сценария.
4. **Фиксировать результат.** После каждого шага явно указывайте, что получилось (успех/ошибка), и при необходимости делайте скриншот или сохраняйте вывод.
5. **Двигаться последовательно.** Не переходите к следующему шагу, пока не завершён текущий и не выведен его результат.

## Пример сценария (Playwright + браузер)

```bash
# Шаг 1: Открыть браузер
echo "[E2E DEMO] Шаг 1: Открываю браузер Chromium..."
npx playwright open chromium --headed &
sleep 3

# Шаг 2: Перейти на страницу
echo "[E2E DEMO] Шаг 2: Перехожу на https://example.com..."
# (здесь может быть вызов Playwright-скрипта)
sleep 2

# Шаг 3: Проверить заголовок
echo "[E2E DEMO] Шаг 3: Проверяю заголовок страницы..."
# ...
echo "[E2E DEMO] Результат: заголовок 'Example Domain' — ОК"
sleep 1

# Шаг 4: Закрыть браузер
echo "[E2E DEMO] Шаг 4: Закрываю браузер..."
# ...
echo "[E2E DEMO] Демонстрация завершена."
```

## Рекомендации по инструментам

- **Playwright** — для браузерных сценариев (открытие страниц, клики, ввод текста).
- **Bash / Shell** — для запуска любых внешних приложений (`xdg-open`, `open`, `start`, `gnome-terminal` и т.п.).
- **`sleep`** — для пауз между действиями.
- **`echo`** — для вывода объяснений в консоль.

## Формат вывода в консоли

Используйте единый префикс `[E2E DEMO]`, чтобы сообщения было легко отличить от обычного вывода OpenCode:

```
[E2E DEMO] ▶ Шаг N: <описание действия>
[E2E DEMO]   ... выполняется ...
[E2E DEMO] ✔ Результат: <что получилось>
[E2E DEMO]   Пауза 2 сек...
```

## Ограничения

- Навык **не заменяет** полноценный фреймворк для E2E-тестов. Он предназначен именно для **демонстрации**.
- Если сценарий требует GUI, убедитесь, что в системе есть графическая среда (X11/Wayland/macOS/Windows).
- При работе в headless-окружении используйте headless-режим Playwright и выводите скриншоты в консоль или сохраняйте их на диск.
